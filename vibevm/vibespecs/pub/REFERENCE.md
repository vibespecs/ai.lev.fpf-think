# Foundational Thinking DPF Suite Reference {#root-2}

> Find the mathematical, physical, computational, modeling or notational contribution your question needs, and understand how the contributions work together.

- **Author:** Anatoly Levenchuk, with AI-assisted development and review
- **Date:** 19 September 2026
- **Status:** Eternal alpha. This edition gives working entries through all five member DPFs and FPF, with their methods, conditions and connections.
- **Publication:** [FPF repository](https://github.com/ailev/FPF)
- **Suite:** [Purpose, membership and edition rules](https://github.com/ailev/FPF/blob/main/Foundational%20Thinking%20DPF%20Suite)

If you have a mathematical question already, start with [Mathematical Thinking](spec://ai.lev/fpf-think-math/pub/TOC#root). If you need to turn a subject question into a mathematical one, start with [Mathematical Modeling](spec://ai.lev/fpf-think-mmp/pub/TOC#root). For a physical account, consequence or observation, start with [Physical Thinking](spec://ai.lev/fpf-think-phy/pub/TOC#root). For algorithm construction, interpretation or analysis, start with [Computational Thinking](spec://ai.lev/fpf-think-cmp/pub/TOC#root). For expressions whose rules, interpretation or changes need repair, start with [Notational Engineering](spec://ai.lev/fpf-think-not/pub/TOC#root). When the difficulty lies between contributions, use the question index below.

The linked patterns describe methods; their results still have to be obtained or supplied for your situation. A small example shows what that use can produce. A missing result can require a specialist contribution or a further method; a reference alone does not supply it.
