# fpf-think — Foundational Thinking DPF Suite

Umbrella of the Foundational Thinking DPF Suite by Anatoly Levenchuk (https://github.com/ailev/FPF, commit `d131d30a44e7`): installing it installs every member DPF package pinned to this version, plus `fpf-common`. Generated by fpf-vibe-gen 0.1.0.

## Install

```bash
vibe install ai.lev/fpf-think --assume-yes
```

Until the packages are published to a registry, install from a checkout of this repository:

```bash
vibe install ai.lev/fpf-think --registry <checkout>/vibevm/vibepacks --offline --assume-yes
```

Keep the project path short on Windows: generated file names are capped, but a deep consumer path can still hit the 260-character limit.
